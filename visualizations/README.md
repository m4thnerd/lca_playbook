# Visualizations

Skills for producing **human-facing visual artifacts** from software systems.
This directory is deliberately separate from `architecture/`: `architecture/`
guides agents reviewing module boundaries and lanes, while `visualizations/`
guides producing high-signal visual posters that give a *human* ground-truth
understanding of a codebase at a glance.

## Skills

- [engineer_architecture_visuals.md](engineer_architecture_visuals.md): dense
  technical infographic posters (backend topology, frontend state, full-stack
  data flow, and cross-repo system boundaries) verified letter-for-letter
  against source code and color-coded by module lane.
