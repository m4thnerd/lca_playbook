# Collaborator Foundations: Supplementary Visual Guides for Less-Technical Collaborators & Solo Builders

These optional, plain-English guides sit outside the core [LCA Playbook](../../README.md) engineering path. Experienced software engineers can skip this folder completely; share it with non-technical teammates (product, design, content, support, ops) or solo non-engineer builders getting started with coding agents.

## Visual Guides in This Folder

1. **[GitHub with an Agent (`github-with-an-agent.md`)](github-with-an-agent.md)** - Ten visual cheat sheets for anyone new to Git and GitHub who wants to collaborate safely on branches and pull requests with an AI agent's help.
2. **[Shaping Rough Ideas into User Stories (`shaping-ideas-into-user-stories.md`)](shaping-ideas-into-user-stories.md)** - Practical, optional ways to turn rough ideas into clear user stories with your agent (Q&A interviews, quick prototypes, or unstructured brainstorms) without letting the agent invent extra scope.
3. **[Infrastructure with an Agent (`infrastructure-with-an-agent.md`)](infrastructure-with-an-agent.md)** - Fourteen visual cards explaining localhost previews, servers, domains, security, backups, and monthly cloud costs (for solo builders shipping their own standalone ideas, or teammates wanting conceptual background vocabulary).

## How to Use These Guides

- **Collaborating inside an established team or company?** Start with **[GitHub with an Agent](github-with-an-agent.md)** and **[Shaping Rough Ideas into User Stories](shaping-ideas-into-user-stories.md)**, and treat **[Infrastructure with an Agent](infrastructure-with-an-agent.md)** purely as shared conceptual vocabulary (never provision servers, domains, or deployments outside your organization's IT, security, and engineering policies).
- **Building a standalone personal or founder project on your own cloud account?** Walk through all three guides in order, pasting each card's `Say to your agent:` prompt into your coding agent session and reading its explanation before approving changes.
- **Ready for the core engineering workflow?** Return to the main **[LCA Playbook README](../../README.md)** or **[Start Here (`docs/start-here/`)](../start-here/mental-model.md)**.
