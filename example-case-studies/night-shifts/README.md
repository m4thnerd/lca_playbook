# Night-Shift Case Studies

Read every case in this directory before leading authorized unattended or
overnight work. Each case distills concrete orchestration, scope-discipline, and
reporting lessons from real multi-hour autonomous runs:

- [A blocked gate is not a stop-work gate](blocked-gate-is-not-stop-work.md)
- [Continuation requires a controller](continuation-requires-a-controller.md)
- [Context is evidence, not scope](context-is-evidence-not-scope.md)
- [Exact-context preflight and explicit continuation](exact-context-preflight-and-continuation.md)
- [A Four-Way Vote Tie and a Report That Asked UI Questions Without Pictures](ui-vote-tie-and-visual-reporting.md)

Transfer the decision questions rather than copying surface mechanics blindly:
missing deployment proof, an idle desktop controller, a tempting adjacent file,
or a split persona vote each require deliberate lead judgment.
